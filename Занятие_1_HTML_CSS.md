# Занятие 1. Знакомство с HTML и CSS

## Цель занятия
Понять, как устроена веб-страница, познакомиться с основными тегами HTML и научиться немного менять внешний вид страницы с помощью CSS: цвет фона, цвет и оформление кнопок.

---

## 1. Из чего состоит веб-страница

Любая веб-страница — это HTML-документ. HTML (HyperText Markup Language) описывает **структуру** страницы: где заголовок, где текст, где картинка. CSS (Cascading Style Sheets) отвечает за **внешний вид**: цвета, шрифты, отступы.

Минимальный "скелет" HTML-страницы выглядит так:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя первая страница</title>
</head>
<body>

</body>
</html>
```

---

## 2. Основные теги и их назначение

### Служебные теги (структура документа)

| Тег | Для чего нужен |
|---|---|
| `<!DOCTYPE html>` | Сообщает браузеру, что документ написан на современном HTML5. Пишется один раз в самом начале файла. |
| `<html>` | Корневой (главный) тег, внутри которого находится вся страница. Всё содержимое сайта — между `<html>` и `</html>`. |
| `<head>` | "Невидимая" часть страницы: сюда пишут название вкладки, кодировку, подключение стилей. Пользователь это не видит на самой странице. |
| `<meta charset="UTF-8">` | Указывает кодировку текста, чтобы кириллица и другие символы отображались правильно, а не "кракозябрами". |
| `<title>` | Текст, который отображается в заголовке вкладки браузера. |
| `<body>` | Видимая часть страницы. Всё, что должно показаться пользователю (текст, картинки, кнопки), пишется внутри этого тега. |
| `<style>` | Тег внутри `<head>`, куда пишутся CSS-стили для оформления страницы. |

### Теги для текста

| Тег | Для чего нужен |
|---|---|
| `<h1>` … `<h6>` | Заголовки разного уровня. `<h1>` — самый крупный и важный (обычно один на странице), `<h6>` — самый мелкий. |
| `<p>` | Абзац текста. Каждый `<p>` начинается с новой строки. |
| `<br>` | Перенос строки внутри текста (без создания нового абзаца). Тег одиночный, закрывающего тега не имеет. |
| `<hr>` | Горизонтальная линия-разделитель между блоками контента. |
| `<span>` | "Обёртка" для небольшого кусочка текста внутри строки, чтобы выделить его стилем (например, покрасить одно слово в предложении). |

### Теги для структуры и списков

| Тег | Для чего нужен |
|---|---|
| `<div>` | Универсальный блок-контейнер. Используется, чтобы сгруппировать несколько элементов вместе и оформить их как единое целое (например, "карточку"). |
| `<ul>` | Маркированный (ненумерованный) список — пункты со значком-точкой. |
| `<ol>` | Нумерованный список — пункты с цифрами. |
| `<li>` | Один пункт списка. Используется только внутри `<ul>` или `<ol>`. |

### Теги для ссылок, картинок и кнопок

| Тег | Для чего нужен |
|---|---|
| `<a href="...">` | Ссылка на другую страницу или сайт. В атрибуте `href` указывается адрес, на который ведёт ссылка. |
| `<img src="..." alt="...">` | Вставка картинки. `src` — путь к файлу изображения, `alt` — текст, который покажется, если картинка не загрузится. |
| `<button>` | Кликабельная кнопка. Пока без "программирования" — просто кнопка на странице, которую можно красиво оформить. |

### Важные атрибуты

| Атрибут | Для чего нужен |
|---|---|
| `class="..."` | Присваивает элементу "имя-категорию", чтобы применить одинаковый стиль сразу к нескольким элементам. |
| `id="..."` | Присваивает элементу уникальное имя (только одно на странице), чтобы применить стиль именно к нему одному. |

## 3. Основы CSS: как менять внешний вид

Стили пишутся внутри тега `<style>` в `<head>` по схеме:

```css
селектор {
    свойство: значение;
}
```

Разберём главные свойства, которые нам понадобятся:

| Свойство | Что делает |
|---|---|
| `background-color` | Цвет фона элемента (или всей страницы, если применить к `body`). |
| `color` | Цвет текста. |
| `font-size` | Размер шрифта. |
| `font-family` | Гарнитура (тип) шрифта. |
| `border` | Рамка вокруг элемента (толщина, стиль, цвет). |
| `border-radius` | Скругление углов элемента — например, чтобы кнопка была не прямоугольной, а с округлыми краями. |
| `padding` | Внутренний отступ — расстояние от текста до края элемента. |
| `margin` | Внешний отступ — расстояние между элементом и соседними элементами. |
| `text-align` | Выравнивание текста: `left`, `center`, `right`. |

**Три способа выбрать, к чему применить стиль (селекторы):**
- `body { ... }` — по названию тега (применится ко всем `<body>`, но он обычно один);
- `.card { ... }` — по классу (точка + имя класса), применится ко всем элементам с `class="card"`;
- `#main-button { ... }` — по id (решётка + имя id), применится только к элементу с этим id.

## 4. Пример: карточка "Обо мне"

Это готовый пример, который мы разбираем на занятии. В нём есть заголовок, фото-заглушка, текст, список увлечений и кнопка. Фон страницы, цвет кнопки и скругление углов — то, что мы специально поменяли с помощью CSS, чтобы показать, как стиль влияет на вид страницы.

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Обо мне</title>
    <style>
        /* Меняем цвет фона всей страницы */
        body {
            background-color: #e6f2ff;
            font-family: Arial, sans-serif;
            text-align: center;
        }

        /* Оформляем карточку */
        .card {
            background-color: #ffffff;
            border-radius: 16px;
            padding: 20px;
            margin: 40px auto;
            width: 320px;
            border: 2px solid #4da6ff;
        }

        h1 {
            color: #005c99;
        }

        .hobbies {
            text-align: left;
            display: inline-block;
        }

        /* Меняем цвет и вид кнопки */
        button {
            background-color: #ff7043;
            color: white;
            border: none;
            padding: 10px 20px;
            border-radius: 8px;
            font-size: 16px;
            cursor: pointer;
        }

        button:hover {
            background-color: #e64a19;
        }
    </style>
</head>
<body>

    <div class="card">
        <h1>Привет, меня зовут Аня!</h1>
        <p>Мне 12 лет, я учусь программировать и очень люблю котиков.</p>

        <hr>

        <p><span style="color: #ff7043; font-weight: bold;">Мои увлечения:</span></p>
        <ul class="hobbies">
            <li>Рисование</li>
            <li>Программирование</li>
            <li>Настольные игры</li>
        </ul>

        <p>Подробнее обо мне на <a href="https://example.com">моей странице</a>.</p>

        <button>Написать мне</button>
    </div>

</body>
</html>
```

## 5. Задание для повторения

Ребята должны создать файл `index.html`, скопировать в него структуру примера выше и **изменить под себя**:

1. Заменить текст в `<h1>` и `<p>` на рассказ о себе.
2. Изменить список увлечений (`<ul>`/`<li>`) на свой.
3. Поменять `background-color` страницы на любой другой цвет (можно посмотреть коды цветов в интернете, например [htmlcolorcodes.com](https://htmlcolorcodes.com)).
4. Поменять цвет кнопки (`background-color` внутри `button`) на другой.
5. По желанию — добавить `<img>` со своей картинкой вместо текста-заглушки.

**Дополнительно (для тех, кто справился быстрее):**
- Добавить ещё одну кнопку с другим цветом.
- Сделать заголовок `<h1>` другого цвета через `color`.
- Добавить `<hr>` в другое место страницы.

## 6. Итог занятия

Сегодня мы узнали:
- из каких обязательных тегов состоит любая HTML-страница;
- какие теги отвечают за заголовки, текст, списки, ссылки, картинки и кнопки;
- как с помощью CSS менять цвет фона, цвет текста, оформление кнопок и скругление углов;
