# Занятие 1. Знакомство с JavaScript

## Цель занятия
Понять, зачем нужен JavaScript, где его писать, познакомиться с переменными, типами данных и научиться делать простую программу, которая спрашивает у пользователя имя и выводит ему персональное приветствие.

---

## 1. Что такое JavaScript и зачем он нужен

Мы уже знаем:
- **HTML** — строит структуру страницы (что где находится);
- **CSS** — отвечает за внешний вид (цвета, отступы, шрифты).

**JavaScript (JS)** — это язык программирования, который добавляет странице **поведение**: реакцию на действия пользователя, вычисления, изменение содержимого "на лету", без перезагрузки страницы.

Пример: когда вы нажимаете "лайк" и цифра рядом сразу увеличивается на 1 без перезагрузки страницы — это работает JavaScript.

---

## 2. Где писать JavaScript-код

Для этого занятия будем использовать тег `<script>` внутри HTML-файла — самый простой способ начать.

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Мой первый скрипт</title>
</head>
<body>

    <script>
        // здесь будет наш JavaScript-код
    </script>

</body>
</html>
```

**Важно:** тег `<script>` ставим перед закрывающим `</body>`, в самом конце — чтобы код выполнялся уже после того, как страница отрисовалась.

---

## 3. Основные понятия для первого знакомства

| Тег / понятие | Для чего нужно |
|---|---|
| `<script>` | Тег, внутри которого пишется JavaScript-код. |
| `//` | Однострочный комментарий — текст после `//` браузер игнорирует. Нужен, чтобы оставлять себе и другим пояснения в коде. |
| `console.log(...)` | Выводит значение в консоль разработчика браузера (открывается клавишей F12). Главный инструмент, чтобы проверить, что код работает правильно. |
| `alert(...)` | Показывает всплывающее окно с сообщением поверх страницы. |
| `prompt(...)` | Показывает окно с полем ввода — так можно спросить у пользователя данные (текст) и сохранить их. |
| `let` | Способ создать переменную — "коробку" с именем, в которую можно положить значение и потом его менять. |
| `const` | Тоже создаёт переменную, но её значение **нельзя** изменить после создания. Используется для значений, которые не должны меняться. |
| `if / else` | Конструкция "если — иначе": позволяет коду принимать решение и выполнять разные действия в зависимости от условия. |

## 4. Переменные: `let` и `const`

Переменная — это именованная "коробочка" для хранения данных.

```javascript
let name = "Аня";     // можно менять значение дальше
const age = 12;        // это значение менять нельзя

name = "Маша";          // сработает — let разрешает менять
age = 13;               // выдаст ошибку — const менять нельзя
```

**Правило для занятия:** если значение точно не будет меняться (например, дата рождения) — используем `const`. Если значение может меняться в ходе программы (например, счёт в игре) — используем `let`.

---

## 5. Типы данных

| Тип | Пример | Описание |
|---|---|---|
| Строка (`string`) | `"Привет"` | Текст, всегда в кавычках (одинарных или двойных). |
| Число (`number`) | `12`, `3.5` | Числа, целые или дробные, без кавычек. |
| Логический (`boolean`) | `true`, `false` | Всего два значения: истина или ложь. Используется в условиях. |

```javascript
let city = "Москва";    // строка
let temperature = 18;    // число
let isSunny = true;      // логическое значение
```

---

## 6. Операторы

**Математические (для чисел):**

| Оператор | Действие |
|---|---|
| `+` | Сложение |
| `-` | Вычитание |
| `*` | Умножение |
| `/` | Деление |

**Оператор `+` для строк** склеивает текст (это называется "конкатенация"):

```javascript
let greeting = "Привет, " + "Аня" + "!";
console.log(greeting); // Привет, Аня!
```

**Операторы сравнения (для условий):**

| Оператор | Значение |
|---|---|
| `===` | Равно (сравнивает точное совпадение — используем именно этот, а не `==`) |
| `!==` | Не равно |
| `>` | Больше |
| `<` | Меньше |
| `>=` | Больше или равно |
| `<=` | Меньше или равно |

## 7. Условие `if / else`

```javascript
let age = 12;

if (age >= 12) {
    console.log("Добро пожаловать на курс!");
} else {
    console.log("Курс для ребят постарше.");
}
```

Код внутри `if (...)` выполнится, только если условие в скобках истинно (`true`). Иначе выполнится код внутри `else`.

## 8. Пример: программа-приветствие

Соберём всё вместе: спросим у пользователя имя и возраст, а затем покажем персональное сообщение прямо на странице.

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Приветствие</title>
    <style>
        body {
            background-color: #f0f8ff;
            font-family: Arial, sans-serif;
            text-align: center;
            padding-top: 60px;
        }

        h1 {
            color: #2b6cb0;
        }

        button {
            background-color: #38a169;
            color: white;
            border: none;
            padding: 12px 24px;
            font-size: 16px;
            border-radius: 8px;
            cursor: pointer;
        }

        button:hover {
            background-color: #2f855a;
        }
    </style>
</head>
<body>

    <h1 id="result">Нажми на кнопку, чтобы начать</h1>
    <button onclick="startGreeting()">Начать</button>

    <script>
        function startGreeting() {
            // Спрашиваем данные у пользователя
            let name = prompt("Как тебя зовут?");
            let age = prompt("Сколько тебе лет?");

            // Собираем текст сообщения
            let message = "Привет, " + name + "! ";

            if (age >= 12) {
                message = message + "Ты уже готов изучать программирование!";
            } else {
                message = message + "Скоро подрастёшь и тоже начнёшь программировать!";
            }

            // Выводим результат на страницу вместо заголовка
            document.getElementById("result").textContent = message;
        }
    </script>

</body>
</html>
```

**Как это работает, по шагам:**
1. По клику на кнопку вызывается функция `startGreeting()`.
2. `prompt(...)` дважды спрашивает данные и сохраняет их в переменные `name` и `age`.
3. Строка `message` собирается склеиванием текста и переменной `name`.
4. Условие `if (age >= 12)` проверяет возраст и добавляет к сообщению разный текст.
5. `document.getElementById("result").textContent = message;` заменяет текст заголовка на нашей странице на итоговое сообщение.
