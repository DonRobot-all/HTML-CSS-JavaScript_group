# Занятие 2. Расположение блоков на странице: Flexbox

## Цель занятия
Научиться располагать несколько блоков на странице в ряд или в столбец, выравнивать их и распределять расстояние между ними с помощью CSS-технологии **Flexbox**. Также вспомним три способа подключения стилей и добавим внешний CSS-файл.

---

## 1. Повторение: три способа задать стиль

Перед новой темой — быстро вспоминаем:

| Способ | Где пишется | Пример |
|---|---|---|
| Инлайн | В самом теге, атрибут `style` | `<h1 style="color: red;">` |
| Внутренний | Тег `<style>` в `<head>` | `h1 { color: red; }` |
| Внешний | Отдельный файл `.css`, подключается через `<link>` | `<link rel="stylesheet" href="style.css">` |

Сегодня познакомимся с **внешним** способом — вынесем стили в отдельный файл `style.css`, чтобы HTML и CSS не смешивались в одном файле. Это то, как делают в реальных проектах.

```html
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <link rel="stylesheet" href="style.css">
</head>
```

Файл `style.css` лежит рядом с `.html`-файлом и содержит просто CSS-код без тега `<style>`:

```css
body {
    background-color: #e6f2ff;
}
```

---

## 2. Проблема: как расположить блоки в ряд?

До сих пор все наши `<div>` и абзацы просто идут друг под другом сверху вниз — это поведение "по умолчанию". Но что, если нужно расположить три карточки **в один ряд**, как на витрине интернет-магазина? Для этого используется **Flexbox**.

---

## 3. Основные теги для примера

Для сегодняшнего примера дополнительно вспомним/добавим:

| Тег | Для чего нужен |
|---|---|
| `<div>` | Как и раньше — универсальный блок-контейнер. Сегодня будем оборачивать группу карточек в один `<div>`-контейнер, а каждую карточку — в свой `<div>`. |
| `<img>` | Вставка картинки внутрь карточки. |
| `<h2>` | Заголовок карточки (чуть меньше, чем `<h1>` — заголовок всей страницы). |
| `<button>` | Кнопка внутри карточки. |

---

## 4. Свойства Flexbox

Чтобы включить flex-режим, у **родительского** блока (контейнера, который оборачивает карточки) указывается:

```css
display: flex;
```

После этого все дочерние элементы внутри автоматически выстраиваются в ряд. Дальше — уточняющие свойства для этого же контейнера:

| Свойство | Что делает |
|---|---|
| `display: flex;` | Включает flex-режим для контейнера — его "дети" выстраиваются в ряд. |
| `flex-direction` | Направление: `row` — в ряд (по умолчанию), `column` — в столбец. |
| `justify-content` | Выравнивание по горизонтали: `center` (по центру), `space-between` (по краям, с равным расстоянием между), `flex-start`, `flex-end`. |
| `align-items` | Выравнивание по вертикали: `center`, `flex-start`, `flex-end`. |
| `gap` | Расстояние между блоками (замена ручным `margin` у каждой карточки). |
| `flex-wrap` | Разрешает блокам переноситься на новую строку, если не помещаются: `wrap`. |

---

## 5. Пример: ряд карточек с товарами

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Витрина</title>
    <style>
        body {
            background-color: #fdf6ec;
            font-family: Arial, sans-serif;
            text-align: center;
        }

        h1 {
            color: #5a3e1b;
        }

        /* Контейнер для рядa карточек */
        .shelf {
            display: flex;
            justify-content: center;
            align-items: stretch;
            gap: 20px;
            flex-wrap: wrap;
            margin-top: 30px;
        }

        /* Одна карточка */
        .item {
            background-color: #ffffff;
            border: 2px solid #d9b382;
            border-radius: 12px;
            padding: 16px;
            width: 180px;
        }

        .item img {
            width: 100%;
            border-radius: 8px;
        }

        button {
            background-color: #d97742;
            color: white;
            border: none;
            padding: 8px 16px;
            border-radius: 6px;
            cursor: pointer;
        }

        button:hover {
            background-color: #0d0908;
        }
    </style>
</head>
<body>

    <h1>Наша витрина</h1>

    <div class="shelf">

        <div class="item">
            <img src="https://via.placeholder.com/150" alt="Кружка">
            <h2>Кружка</h2>
            <p>350 ₽</p>
            <button>В корзину</button>
        </div>

        <div class="item">
            <img src="https://via.placeholder.com/150" alt="Блокнот">
            <h2>Блокнот</h2>
            <p>220 ₽</p>
            <button>В корзину</button>
        </div>

        <div class="item">
            <img src="https://via.placeholder.com/150" alt="Стикеры">
            <h2>Стикеры</h2>
            <p>90 ₽</p>
            <button>В корзину</button>
        </div>

    </div>

</body>
</html>
```

Обратите внимание на структуру: снаружи один большой `<div class="shelf">` (это контейнер с `display: flex`), а внутри него — три одинаковых `<div class="item">` (сами карточки). Именно контейнеру задаётся `display: flex`, а не карточкам внутри него.

## 6. Задание для повторения

1. Скопировать пример и заменить товары на свои три (можно не про магазин — например, "мои три любимых фильма" или "три моих питомца").
2. Поменять `justify-content` на `space-between` и посмотреть, как изменится расположение карточек.
3. Поменять `flex-direction` на `column` и посмотреть, что получится.
4. Изменить `background-color` карточек и кнопок на свои цвета.
5. Поменять `gap` на большее или меньшее значение — посмотреть, как меняется расстояние между карточками.

**Дополнительно:**
- Добавить четвёртую карточку и убедиться, что `flex-wrap: wrap` переносит её на новую строку, если места не хватает (можно проверить, сузив окно браузера).
- Попробовать вынести стили в отдельный файл `style.css`, как разобрали в начале занятия.

Сегодня мы узнали:

- что такое Flexbox и зачем он нужен;

- как выравнивать блоки по горизонтали и вертикали (`justify-content`, `align-items`);
