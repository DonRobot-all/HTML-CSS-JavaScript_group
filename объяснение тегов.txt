    inset: 0;             /* Растягивает контейнер на весь экран:
                             top: 0; right: 0; bottom: 0; left: 0. */

    z-index: 0;           /* Задаёт слой фона.
                             Контент с z-index: 1 будет поверх него. */

    z-index: 1;           /* Размещает содержимое выше фона,
                             у которого z-index: 0. */

    overflow: hidden;     /* Скрывает части изображений, выходящие
                             за границы контейнера. */

    background-size: cover; /* Масштабирует изображение так, чтобы
                               оно полностью покрыло контейнер.
                               Края могут обрезаться. */

    background-position: center; /* Размещает центр изображения
                                    по центру контейнера. */

    background-repeat: no-repeat; /* Запрещает повторять изображение,
                                     если оно меньше контейнера. */

    opacity: 0;           /* По умолчанию изображение полностью прозрачно.
                             Его не видно. */
    opacity: 1;           /* изображение становится полностью видимым. */
    
    transition: opacity 1.5s ease-in-out;
    /* Плавно меняет прозрачность за 1,5 секунды:
       ease-in-out — плавное начало и завершение перехода. */



position — одно из самых важных свойств CSS. Оно определяет, как элемент располагается на странице и относительно чего браузер рассчитывает его положение.
1. static — обычное положение (По умолчанию)
Элемент располагается в обычном порядке HTML. Свойства top, left, right и bottom не сдвигают его.
.block {
    position: static;
}

2. relative — относительно своего места
Элемент остаётся в обычном потоке страницы, но его можно визуально сдвинуть от исходного положения. Его первоначальное место сохраняется.
.block {
    position: relative;
    top: 10px;
    left: 20px;
}
ps. Элемент сдвинется на 10 пикселей вниз и на 20 пикселей вправо.
Ещё одна важная роль: relative часто задают родителю, чтобы вложенный элемент с position: absolute позиционировался относительно него.

3. absolute — точное позиционирование
Элемент обычно исключается из обычного потока страницы и размещается относительно ближайшего предка, у которого position не static.
.card {
    position: relative;
}

.icon {
    position: absolute;
    top: 10px;
    right: 10px;
}
Пример: значок в правом верхнем углу карточки. Другие элементы ведут себя так, будто значок не занимает места в потоке.

4. fixed — закрепление на экране
Элемент позиционируется относительно окна браузера и обычно остаётся на месте при прокрутке страницы.
.menu {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
}

5. sticky — прилипание при прокрутке
Сначала элемент ведёт себя как обычный, но при прокрутке может закрепиться у заданной границы внутри области прокрутки.
.menu {
    position: sticky;
    top: 0;
}
Пример: меню остаётся сверху, когда пользователь прокручивает содержимое вниз. Для работы обычно нужен заданный порог, например top: 0.
