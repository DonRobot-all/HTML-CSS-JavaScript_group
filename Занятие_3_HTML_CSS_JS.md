# Занятие 3. Добавляем интерактивность с JavaScript

## Цель занятия
Узнать, зачем нужен JavaScript, чем он отличается от HTML и CSS, и научиться делать так, чтобы кнопка на странице реально что-то делала: меняла текст, цвет фона, показывала сообщение.

---

## 1. Три языка — три роли

Вспомним, что мы уже знаем, и добавим третий кирпичик:

| Язык | За что отвечает | Аналогия |
|---|---|---|
| HTML | Структура страницы (что где находится) | Стены и комнаты дома |
| CSS | Внешний вид (цвета, отступы, расположение) | Обои, мебель, дизайн |
| **JavaScript** | **Поведение и логика (что происходит по действиям)** | **Электричество и "умные" устройства в доме** |

До сих пор наши кнопки `<button>` были просто красиво оформлены, но ничего не делали при нажатии. Сегодня это исправим.

---

## 2. Как подключить JavaScript к странице

Так же, как и CSS, JS можно подключить тремя способами:

| Способ | Где пишется |
|---|---|
| Инлайн | Атрибут `onclick="..."` прямо в теге |
| Внутренний | Тег `<script>` внутри `<body>` (обычно в самом конце, перед `</body>`) |
| Внешний | Отдельный файл `.js`, подключается через `<script src="script.js"></script>` |

Пример внутреннего подключения:

```html
<body>

    <!-- весь HTML-контент страницы -->

    <script>
        // здесь пишется JavaScript-код
    </script>
</body>
```

**Важно:** тег `<script>` ставят в конце `<body>`, а не в `<head>`, — чтобы браузер сначала отрисовал всю страницу, и только потом запускал код, который с этой страницей работает.

---

## 3. Основные понятия JavaScript для первого знакомства

| Тег / понятие | Для чего нужно |
|---|---|
| `<script>` | Тег, внутри которого пишется JavaScript-код (или через который подключается внешний `.js`-файл). |
| `onclick="..."` | Атрибут HTML-тега, который запускает JS-код при клике на этот элемент. |
| `function` | Способ "завернуть" несколько действий в один именованный блок, чтобы потом вызывать их одной командой. |
| `alert("...")` | Показывает пользователю всплывающее окно с сообщением. Самый простой способ проверить, что код вообще работает. |
| `document.getElementById("...")` | Находит на странице элемент по его `id`, чтобы потом с ним что-то сделать (изменить текст, цвет и т.д.). |
| `.textContent` | Свойство, через которое можно прочитать или изменить текст внутри элемента. |
| `.style.свойство` | Позволяет менять CSS-свойство элемента прямо из JavaScript (например, `.style.backgroundColor`). |
| `addEventListener("click", функция)` | Более "правильный" способ повесить действие на клик — используется вместо `onclick`, когда кода становится больше. |

---

## 4. Первый шаг: alert по клику

Самый простой пример — инлайн-способ:

```html
<button onclick="alert('Привет! Ты нажал на кнопку.')">Нажми меня</button>
```

Разберём: атрибут `onclick` содержит JS-команду `alert(...)`, которая выполнится в момент клика. Текст сообщения пишется в кавычках внутри скобок.

## 5. Пример: карточка "Обо мне" оживает

Возьмём карточку с прошлого занятия и добавим ей два рабочих элемента:
- кнопка "Написать мне" теперь показывает сообщение;
- кнопка "Сменить цвет" меняет цвет фона карточки на случайный.

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Обо мне</title>
    <style>
        body {
            background-color: #e6f2ff;
            font-family: Arial, sans-serif;
            text-align: center;
        }

        .card {
            background-color: #ffffff;
            border-radius: 16px;
            padding: 20px;
            margin: 40px auto;
            width: 320px;
            border: 2px solid #4da6ff;
            transition: background-color 0.3s;
        }

        h1 {
            color: #005c99;
        }

        button {
            background-color: #ff7043;
            color: white;
            border: none;
            padding: 10px 20px;
            border-radius: 8px;
            font-size: 16px;
            cursor: pointer;
            margin: 5px;
        }

        button:hover {
            background-color: #e64a19;
        }
    </style>
</head>
<body>

    <div class="card" id="myCard">
        <h1>Привет, меня зовут Аня!</h1>
        <p id="greeting">Мне 12 лет, я учусь программировать.</p>

        <button onclick="sayHello()">Написать мне</button>
        <button onclick="changeColor()">Сменить цвет карточки</button>
    </div>

    <script>
        // Функция для кнопки "Написать мне"
        function sayHello() {
            alert("Спасибо, что заглянули! Скоро отвечу.");
        }

        // Функция для кнопки "Сменить цвет карточки"
        function changeColor() {
            const colors = ["#ffe0e0", "#e0ffe0", "#e0f0ff", "#fff5cc"];
            const randomColor = colors[Math.floor(Math.random() * colors.length)];
            document.getElementById("myCard").style.backgroundColor = randomColor;
        }
    </script>

</body>
</html>
```

**Как это работает, по шагам:**
1. У карточки указан `id="myCard"` — это "имя", по которому JS сможет её найти.
2. При клике на первую кнопку вызывается функция `sayHello()`, которая просто показывает `alert`.
3. При клике на вторую кнопку вызывается `changeColor()`: она выбирает случайный цвет из списка `colors` и через `document.getElementById("myCard")` находит карточку, а затем меняет её `style.backgroundColor`.
