# JavaScript: вводная база (в сравнении с Python)

Этот конспект — самостоятельный ввод в базовый синтаксис JavaScript: переменные, условия, циклы, функции, ввод и вывод. Без привязки к HTML — весь код можно проверить прямо в консоли браузера (клавиша F12 → вкладка Console) или через Node.js.

---

## 1. Где выполнять код

- **Консоль браузера** — открыть любую страницу, нажать F12, вкладка "Console", писать код прямо туда и жать Enter.
- **Node.js** — если установлен на компьютере, можно писать код в файле `script.js` и запускать командой `node script.js` из терминала — почти как `python script.py`.

Все примеры ниже можно проверить любым из этих способов.

---

## 2. Вывод текста

| Python | JavaScript |
|---|---|
| `print("Привет")` | `console.log("Привет")` |

```javascript
console.log("Привет, мир!");
console.log("Значение x:", 5);   // можно перечислить несколько значений через запятую
```

**Нюанс:** `console.log` пишет в консоль разработчика, а не "на экран" пользователю. Если код выполняется в браузере и нужно показать сообщение именно пользователю (всплывающим окном), используется `alert("Привет")` — но это отдельная функция, не замена `console.log`.

## 3. Ввод текста

| Python | JavaScript (в браузере) |
|---|---|
| `name = input("Как тебя зовут? ")` | `let name = prompt("Как тебя зовут?");` |

```javascript
let name = prompt("Как тебя зовут?");
console.log("Привет, " + name);
```

**Важный нюанс:** `prompt()` работает только в браузере (это часть окна браузера, а не языка JS как такового). В Node.js `prompt()` не существует — там для ввода данных с клавиатуры нужен отдельный модуль (`readline`), это чуть сложнее и на первом занятии не понадобится.

**Ещё нюанс:** и `prompt()`, и `input()` всегда возвращают **строку**, даже если пользователь ввёл число. Если нужно посчитать введённое число, его нужно предварительно преобразовать:

```javascript
let ageText = prompt("Сколько тебе лет?");
let age = Number(ageText);          // превращаем строку в число
console.log(age + 1);                // теперь можно складывать как число
```

В Python то же самое: `age = int(input("Сколько тебе лет? "))`.

## 4. Переменные

| Python | JavaScript |
|---|---|
| `x = 5` | `let x = 5;` |
| — (переменные всегда изменяемы) | `const x = 5;` — значение менять нельзя |

```javascript
let score = 10;
score = 15;          // сработает — let разрешает менять

const pi = 3.14;
pi = 3;               // ОШИБКА — const менять нельзя
```

**Главный нюанс, которого нет в Python:** в JS переменную обязательно нужно объявлять специальным словом (`let` или `const`). В Python достаточно просто написать `x = 5`.

Есть ещё старое `var` — работает похоже на `let`, но с историческими особенностями, которые сейчас считаются источником багов. **Правило:** в новом коде `var` не используем, только `let` и `const`.

**Когда что использовать:** если значение точно не изменится за время работы программы — `const` (это как бы "по умолчанию" в современном JS). Если планируется менять — `let`.

## 5. Типы данных

| Тип | Python | JavaScript |
|---|---|---|
| Строка | `str`, например `"привет"` | `string`, например `"привет"` |
| Целое/дробное число | `int` и `float` — два разных типа | `number` — **один** тип для всех чисел |
| Логическое значение | `True` / `False` | `true` / `false` (с маленькой буквы!) |
| Пустое значение | `None` | `null` и `undefined` — два разных понятия |

```javascript
let city = "Москва";     // string
let temperature = -3.5;   // number (JS не различает int и float)
let isRaining = false;    // boolean
```

**Нюанс про `null` и `undefined`:**
- `undefined` — переменная объявлена, но значения ей не присвоили (JS сам так её пометил).
- `null` — значение "специально ничего", записанное осознанно программистом.

```javascript
let a;
console.log(a);       // undefined — переменную объявили, но не задали значение

let b = null;
console.log(b);        // null — мы сами явно сказали "пусто"
```

В Python есть только одно понятие для этого — `None`.

## 6. Операторы

### Математические — почти одинаковые

| Оператор | Python | JavaScript |
|---|---|---|
| Сложение | `+` | `+` |
| Вычитание | `-` | `-` |
| Умножение | `*` | `*` |
| Деление | `/` | `/` |
| Остаток от деления | `%` | `%` |
| Возведение в степень | `**` | `**` |

### Строки — конкатенация

```python
# Python
greeting = "Привет, " + "Аня"
```
```javascript
// JavaScript
let greeting = "Привет, " + "Аня";
```

Работает одинаково. Но в JS есть ещё удобный способ — **шаблонные строки** (аналог f-строк в Python):

```python
# Python
name = "Аня"
greeting = f"Привет, {name}!"
```
```javascript
// JavaScript — обратные кавычки ` вместо обычных
let name = "Аня";
let greeting = `Привет, ${name}!`;
```

### Сравнение — здесь главный нюанс занятия

| Оператор | Python | JavaScript | Что делает |
|---|---|---|---|
| Равно | `==` | `==` | Сравнивает **значения**, при необходимости "подгоняя" типы друг под друга |
| Равно (строго) | нет отдельного | `===` | Сравнивает **и значение, и тип**, без всякого подгона |
| Не равно | `!=` | `!=` / `!==` | Аналогично, но "не равно" |

**Вот в чём разница между `==` и `===` в JavaScript:**

```javascript
console.log(5 == "5");    // true  — JS сам превращает строку "5" в число и сравнивает
console.log(5 === "5");   // false — типы разные (number и string), значит не равно

console.log(0 == false);   // true  — JS считает 0 и false "похожими"
console.log(0 === false);  // false — разные типы (number и boolean)
```

В Python такой путаницы нет — `5 == "5"` в Python сразу даёт `False`, потому что Python не сравнивает разные типы "приблизительно".

**Правило, которое стоит запомнить сразу:** в JavaScript **всегда используем `===` и `!==`**, а не `==` и `!=`, чтобы не попадать в ситуации с неожиданным поведением, как в примерах выше.

### Логические операторы

| Python | JavaScript | Значение |
|---|---|---|
| `and` | `&&` | И (оба условия истинны) |
| `or` | `\|\|` | ИЛИ (хотя бы одно условие истинно) |
| `not` | `!` | НЕ (отрицание) |

```javascript
let age = 20;
let hasTicket = true;

if (age >= 18 && hasTicket) {
    console.log("Проходите");
}
```

## 7. Условия: `if / else`

```python
# Python
age = 20

if age >= 18:
    print("Взрослый")
elif age >= 13:
    print("Подросток")
else:
    print("Ребёнок")
```

```javascript
// JavaScript
let age = 20;

if (age >= 18) {
    console.log("Взрослый");
} else if (age >= 13) {
    console.log("Подросток");
} else {
    console.log("Ребёнок");
}
```

**Ключевые синтаксические отличия:**

| | Python | JavaScript |
|---|---|---|
| Условие в скобках | не нужны | **обязательны** `( )` |
| Тело условия | отступами (пробелы) | фигурными скобками `{ }` |
| "иначе если" | `elif` | `else if` (два слова) |
| Двоеточие после условия | нужно `:` | не нужно |

**Важный нюанс:** в JS отступы вообще не влияют на работу кода — только на читаемость для человека. Технически весь код можно написать в одну строку, и он будет работать так же. Но **хорошим стилем** всё равно считается делать отступы, как в Python — просто их расставляет не сам язык, а программист (или редактор кода).

## 8. Циклы

### `for` — счётный цикл

```python
# Python
for i in range(5):
    print(i)
```

```javascript
// JavaScript
for (let i = 0; i < 5; i++) {
    console.log(i);
}
```

Синтаксис `for` в JS состоит из трёх частей через точку с запятой:
1. `let i = 0` — начальное значение счётчика;
2. `i < 5` — условие, пока цикл продолжается;
3. `i++` — что происходит с счётчиком после каждого повторения (`i++` значит "увеличить на 1", короткая запись для `i = i + 1`).

### `while` — цикл "пока условие истинно"

```python
# Python
count = 0
while count < 3:
    print(count)
    count += 1
```

```javascript
// JavaScript
let count = 0;
while (count < 3) {
    console.log(count);
    count++;
}
```

Здесь синтаксис почти идентичен по смыслу, разница та же: скобки вокруг условия и фигурные скобки вместо отступов.

### Перебор списка (массива)

```python
# Python
fruits = ["яблоко", "банан", "груша"]
for fruit in fruits:
    print(fruit)
```

```javascript
// JavaScript
let fruits = ["яблоко", "банан", "груша"];
for (let fruit of fruits) {
    console.log(fruit);
}
```

`for...of` — аналог `for x in list` в Python: перебирает **сами значения** массива по очереди.

## 9. Функции

```python
# Python
def greet(name):
    return "Привет, " + name

print(greet("Аня"))
```

```javascript
// JavaScript — способ 1: обычное объявление функции
function greet(name) {
    return "Привет, " + name;
}

console.log(greet("Аня"));
```

**Ключевые отличия:**

| | Python | JavaScript |
|---|---|---|
| Ключевое слово | `def` | `function` |
| Скобки для аргументов | обязательны | обязательны (совпадает) |
| Тело функции | отступами | фигурные скобки `{ }` |
| Возврат значения | `return` | `return` (совпадает) |
| Двоеточие после объявления | нужно `:` | не нужно |

**В JS есть ещё один, более новый способ — стрелочная функция:**

```javascript
// JavaScript — способ 2: стрелочная функция
const greet = (name) => {
    return "Привет, " + name;
};

console.log(greet("Аня"));
```

Если функция состоит из одной строки с `return`, её можно ещё сократить:

```javascript
const greet = (name) => "Привет, " + name;
```

В Python прямого аналога такой сверхкороткой записи нет (есть `lambda`, но она устроена немного иначе и используется реже, чем стрелочные функции в JS).

## 10. Сводная таблица различий

| | Python | JavaScript |
|---|---|---|
| Вывод | `print()` | `console.log()` |
| Ввод (в браузере) | `input()` | `prompt()` |
| Создание переменной | `x = 5` | `let x = 5;` или `const x = 5;` |
| Точка с запятой | не нужна | по хорошему стилю ставится `;` в конце команды |
| Границы блока кода | отступы (пробелы) | фигурные скобки `{ }` |
| Скобки вокруг условия `if` | не нужны | обязательны |
| "иначе если" | `elif` | `else if` |
| Равенство | `==` | `===` (строгое, используем его) / `==` (нестрогое, избегаем) |
| И / ИЛИ / НЕ | `and` / `or` / `not` | `&&` / `\|\|` / `!` |
| Целые и дробные числа | два типа: `int`, `float` | один тип: `number` |
| Пустое значение | `None` | `null` и `undefined` — два понятия |
| f-строки | `f"Привет, {name}"` | `` `Привет, ${name}` `` (обратные кавычки) |
| Функция | `def name():` | `function name() { }` или `const name = () => { }` |
| Список | `[1, 2, 3]` (list) | `[1, 2, 3]` (array) — синтаксис совпадает |

## 11. Итог занятия

Сегодня разобрали:
- как выводить и вводить данные (`console.log`, `prompt`, разница с `print`/`input`);
- переменные `let` и `const`, обязательность ключевого слова при создании (в отличие от Python);
- типы данных, и почему в JS одно число `number` вместо `int`/`float`;
- главный нюанс — разницу между `==` и `===`, и почему всегда используем строгое сравнение;
- условия `if/else` и их синтаксические отличия от Python (скобки вместо `:`, `{ }` вместо отступов);
- циклы `for` и `while`, а также `for...of` для перебора массивов;
- функции — как через `function`, так и через более новую стрелочную запись.

Главный вывод: **логика программирования не отличается от Python** — если вы понимаете, зачем нужны переменные, условия и циклы, вам нужно освоить только **синтаксис** JS, а не учиться программировать заново.
