# Занятие 4. Формы и поля ввода

## Цель занятия
Научиться создавать на странице поля, в которые пользователь может что-то ввести (текст, email, выбрать вариант из списка), красиво их оформить, и с помощью JavaScript считать то, что ввёл пользователь, — без перезагрузки страницы.

---

## 1. Зачем нужны формы

Всё, с чем мы работали раньше (текст, картинки, кнопки), пользователь мог только **смотреть**. Форма — это способ дать пользователю **ввести** свои данные: имя в форме регистрации, сообщение в форме обратной связи, товар в корзине.

---

## 2. Основные теги для форм

| Тег | Для чего нужен |
|---|---|
| `<form>` | "Обёртка" для всей формы. Все поля ввода и кнопка отправки находятся внутри него. |
| `<input>` | Основное поле ввода. Одиночный тег (без закрывающего). Что именно вводит пользователь, определяется атрибутом `type` (см. таблицу ниже). |
| `<label>` | Подпись к полю. Если связать её с полем через атрибут `for`, то клик по подписи тоже ставит курсор в поле — это удобно и важно для доступности. |
| `<textarea>` | Многострочное текстовое поле — для длинных сообщений (в отличие от `<input type="text">`, который однострочный). |
| `<select>` | Выпадающий список. Внутри него — несколько `<option>`. |
| `<option>` | Один вариант внутри `<select>`. |
| `<button type="submit">` | Кнопка отправки формы. |

---

## 3. Типы `<input>`

Атрибут `type` у `<input>` меняет и то, как поле выглядит, и то, что браузер разрешает туда вводить:

| `type` | Что это |
|---|---|
| `text` | Обычное однострочное текстовое поле. |
| `email` | Поле для email — браузер сам проверит, что введён текст в формате `что-то@что-то.что-то`. |
| `password` | Поле для пароля — введённые символы скрываются точками. |
| `number` | Поле только для чисел — со стрелочками "плюс/минус". |
| `checkbox` | Флажок "да/нет" — можно выбрать несколько сразу. |
| `radio` | Переключатель "один из нескольких" — если несколько `radio` имеют одинаковый `name`, можно выбрать только один из них. |
| `submit` | Кнопка отправки (то же самое, что `<button type="submit">`, только в виде `input`). |

---

## 4. Важные атрибуты полей

| Атрибут | Для чего нужен |
|---|---|
| `name` | "Имя" поля — по нему потом можно получить его значение (особенно важно для `radio` — их объединяют одинаковым `name`). |
| `id` | Уникальный идентификатор — по нему поле находит JavaScript (`document.getElementById`) и связывается `<label for="...">`. |
| `placeholder` | Серая подсказка внутри поля, которая исчезает при вводе (например, "Введите ваше имя"). Это **не** значение по умолчанию, а просто подсказка. |
| `required` | Делает поле обязательным — браузер не даст отправить форму, пока оно не заполнено. |
| `value` | Значение поля. Можно задать заранее (текст по умолчанию) или считать текущее значение через JavaScript. |

---

## 5. Немного CSS для полей ввода

Поля по умолчанию выглядят у всех браузеров немного по-разному и довольно "сухо" — обычно их стилизуют:

```css
input, textarea, select {
    width: 100%;
    padding: 10px;
    margin-bottom: 12px;
    border: 2px solid #cbd5e0;
    border-radius: 8px;
    font-size: 15px;
    box-sizing: border-box; /* чтобы padding не увеличивал итоговую ширину */
}

/* Стиль при клике в поле (в фокусе) */
input:focus, textarea:focus {
    border-color: #4da6ff;
    outline: none;
}
```

`:focus` — ещё один псевдокласс, как уже знакомый нам `:hover`, только срабатывает, когда поле **активно** (пользователь кликнул в него и может печатать).

---

## 6. JavaScript: считываем то, что ввёл пользователь

Чтобы получить значение поля, используется уже знакомый `document.getElementById(...)`, только вместо `.textContent` — свойство **`.value`**:

```javascript
let userName = document.getElementById("nameField").value;
```

**Важный момент про отправку формы:** по умолчанию, когда пользователь нажимает кнопку `submit`, браузер пытается **перезагрузить страницу** и отправить данные на сервер. Раз у нас пока нет сервера, эту перезагрузку нужно отменить командой `event.preventDefault()`.

---

## 7. Пример: форма обратной связи

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Обратная связь</title>
    <style>
        body {
            background-color: #f0f8ff;
            font-family: Arial, sans-serif;
            text-align: center;
            padding-top: 40px;
        }

        form {
            background-color: white;
            width: 320px;
            margin: 0 auto;
            padding: 24px;
            border-radius: 16px;
            box-shadow: 0 8px 20px rgba(0, 76, 153, 0.2);
            text-align: left;
        }

        label {
            font-weight: bold;
            color: #005c99;
        }

        input, textarea, select {
            width: 100%;
            padding: 10px;
            margin: 6px 0 16px 0;
            border: 2px solid #cbd5e0;
            border-radius: 8px;
            font-size: 15px;
            box-sizing: border-box;
        }

        input:focus, textarea:focus, select:focus {
            border-color: #4da6ff;
            outline: none;
        }

        button {
            background-color: #ff7043;
            color: white;
            border: none;
            padding: 12px 20px;
            border-radius: 8px;
            font-size: 16px;
            cursor: pointer;
            width: 100%;
        }

        button:hover {
            background-color: #e64a19;
        }

        #resultMessage {
            width: 320px;
            margin: 20px auto 0 auto;
            font-weight: bold;
            color: #005c99;
        }
    </style>
</head>
<body>

    <form id="feedbackForm">
        <label for="nameField">Как вас зовут?</label>
        <input type="text" id="nameField" placeholder="Введите имя" required>

        <label for="emailField">Email</label>
        <input type="email" id="emailField" placeholder="mail@example.com" required>

        <label for="topicField">Тема обращения</label>
        <select id="topicField">
            <option value="Вопрос">Вопрос</option>
            <option value="Предложение">Предложение</option>
            <option value="Жалоба">Жалоба</option>
        </select>

        <label for="messageField">Сообщение</label>
        <textarea id="messageField" rows="4" placeholder="Ваше сообщение..." required></textarea>

        <button type="submit">Отправить</button>
    </form>

    <p id="resultMessage"></p>

    <script>
        // Находим форму и "слушаем" момент отправки
        const form = document.getElementById("feedbackForm");

        form.addEventListener("submit", function (event) {
            // Отменяем стандартную перезагрузку страницы
            event.preventDefault();

            // Считываем значения полей
            let name = document.getElementById("nameField").value;
            let topic = document.getElementById("topicField").value;

            // Формируем и показываем сообщение
            let message = "Спасибо, " + name + "! Ваше обращение по теме «" + topic + "» принято.";
            document.getElementById("resultMessage").textContent = message;
        });
    </script>

</body>
</html>
```

**Как это работает, по шагам:**
1. `document.getElementById("feedbackForm")` находит саму форму по `id`.
2. `form.addEventListener("submit", function (event) { ... })` — вешает "слушателя" на момент отправки формы (это ещё один способ обработки событий, помимо знакомого нам `onclick`).
3. `event.preventDefault()` — отменяет перезагрузку страницы браузером.
4. Значения полей считываются через `.value` и собираются в одно сообщение.
5. Результат выводится в `<p id="resultMessage">` — без перезагрузки, мгновенно.

## 8. Задание для повторения

1. Скопировать пример и добавить своё поле — например, `<input type="number">` для возраста.
2. Добавить это новое поле в итоговое сообщение (`message`).
3. Добавить `<input type="checkbox">` с подписью "Согласен на обработку данных" и проверить в JS через `.checked` (а не `.value`), отмечен ли чекбокс — и вывести это в сообщении ("Согласие получено" / "Согласие не отмечено").
4. Оформить форму под свой стиль — свой `border-radius`, `box-shadow`, цвета из предыдущих занятий.

**Дополнительно (для тех, кто справился быстрее):**
- Добавить `<input type="radio">` для выбора "Срочно / Не срочно" (с одинаковым `name`) и учитывать выбор в сообщении.
- Сделать так, чтобы после отправки сама форма скрывалась (`form.style.display = "none";`), а оставалось только сообщение.

## 9. Итог занятия

Сегодня мы узнали:
- зачем нужна форма и какие бывают типы `<input>`;
- как связать `<label>` с полем через `for`/`id`;
- как оформить поля через CSS, включая состояние `:focus`;
- как считать значения полей в JavaScript через `.value`;
- как обработать отправку формы через `addEventListener("submit", ...)` и `event.preventDefault()`.

Это завершает основы фронтенда, которые мы разбирали: HTML-структура, CSS-оформление и JS-интерактивность. Дальше можно двигаться в сторону более сложных тем — адаптивность под телефоны (media queries) или CSS Grid для сложных раскладок.
